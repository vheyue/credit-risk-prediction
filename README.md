# credit-risk-prediction
Machine Learning project for predicting credit default risk using Python and scikit-learn.
# Objetives
- Explore and clean a credit risk dataset
- Identify relevant variables associated with loan defaults
- Train and avaluate classification models
- Interpret results and provide business recommendations
# Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
